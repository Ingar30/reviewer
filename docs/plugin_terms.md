# Economics Paper Reviewer: use and limitations

**Draft for publisher review; not yet approved public terms.** Prepared 2026-09-09.
The publisher must confirm the identity, support arrangement and suitability of
these statements before submission. This page is not legal advice.

The software remains open source under the repository's
[MIT license](https://github.com/Ingar30/reviewer/blob/main/LICENSE.md), including
its warranty disclaimer and liability provisions. Plugin distribution does not
replace that license or introduce a separate paid Reviewer service.

- Upload only material you are entitled to process and share with the selected
  host and, when enabled, its web tools. Respect confidentiality, consent, copyright
  and institutional requirements. See the [data-flow description](plugin_privacy.md).
- Reviewer provides AI-generated assistance, not a journal decision, certification
  of correctness, plagiarism guarantee or substitute for a qualified human review.
  Check findings against the paper and original evidence before relying on them.
  False positives, missed defects and incomplete external verification are possible.
- Full/Lite describe workflow profiles, not guaranteed model settings, quality,
  speed or savings. Lite retains coverage and is unbenchmarked. The host determines
  available models, tools and actual usage accounting.
- Native reviews use the host's available ChatGPT Work/Codex allowance. No model API
  key or API credits are required by this package. Included usage can be exhausted;
  a plan is not a promise of unlimited reviews. The plugin does not purchase credits,
  authorize charges or circumvent host limits. OpenAI's service terms still apply.
- Completion requires native subagents, file execution, image access and working
  Python PDF dependencies in the chosen host. Some environments need a permission-
  gated isolated setup. Scanned, damaged, protected or poorly extracted PDFs may
  prevent a complete review. The plugin must disclose failures rather than invent
  evidence or claim unsupported cloud capabilities.
- Save and handle reports/checkpoints appropriately. Resume requires a compatible
  runtime and intact artifacts; cross-version migration and host storage durability
  are not guaranteed. Public updates are versioned snapshots, not live `main` changes.
- Support is best-effort through [public GitHub issues](https://github.com/Ingar30/reviewer/issues)
  using non-sensitive reproductions. There is no promised response time, uptime or
  institutional service agreement. Future paid offerings would require separate
  terms; they are not part of this open-source package.
