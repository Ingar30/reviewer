Artifact interpretation rules:
- Normalized page markdown begins with a generated `# Page ... (label: ...)` metadata header. Do not count that header as retained manuscript footer/header text; test only the normalized body below the first blank line.
- A `layout_artifacts.json` entry is provenance that a geometric candidate was handled, not evidence that its text remains in normalized prose. Compare the normalized body with raw text and the page image before reporting retained or damaged content.
- For a figure whose inventory uses `crop_strategy: full_page_rotated_fallback`, compare its file size, pixel dimensions, and hash with the corresponding page image before alleging a blank or truncated crop. If the files are byte-identical, treat the page image as confirmation that the crop is complete.
- For a table whose inventory uses `crop_strategy: full_page_multi_panel_fallback`, the crop is deliberately a complete-page visual fallback. Compare it with the page image before alleging that later panels or notes are absent. This strategy does not certify the structured cells; continue to audit the CSV/markdown independently.

Table inventory status rules:
- `caption_matched_table` and `caption_anchored_table` inventory roles are canonical table objects. `unlabeled_candidate` objects are retained extraction candidates, not canonical tables; audit them for missed captions or false positives. The manifest `table_count` excludes these candidates, while `table_candidate_count` retains the full candidate count.
- `auto_extracted_suspect`, `caption_text_contaminated`, and `caption_text_unstructured` are unsafe as primary evidence.
- `auto_extracted_needs_visual_verification` and `caption_text_needs_visual_verification` are deterministic candidates, not verified tables. Compare them with the cited page image or crop before relying on column alignment, signs, or values.
- Never infer missing cells, signs, values, or formulas to make a table look complete.

Use these severity rules:
- high: downstream reviewers cannot safely operate on a major evidence class or substantial page range, and no usable page-text/image fallback exists
- medium: reviewers can proceed, but one evidence class or important object may be incomplete or misleading; use this for missing table/figure inventories when page text or page images still provide usable fallback evidence
- low: localized parser defect or cleanup issue
